# SmartDSP

SmartDSP is a Linux-based high-resolution audio DSP platform combining
CamillaDSP, PipeWire/JACK, nonlinear voicing, metering, visualization,
routing, and system management into a single audio processing appliance.

**Current reference processing path:** 192 kHz / S32_LE stereo.

Documentation and installation tooling are currently being prepared for
the first public release.
